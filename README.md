# fire-salamander-surveillance

A reproducible R workflow exploring fire salamander (*Salamandra salamandra*)
distribution and survey coverage in the Mosel/Eifel region, built toward a
surveillance-gap map for the salamander-plague pathogen *Batrachochytrium
salamandrivorans* (Bsal).

**Status:** work in progress — a learning/portfolio project, not a published result.

## Data & ethics
Occurrence records are drawn from open, openly-licensed sources via GBIF
(which aggregates iNaturalist, Observation.org and national atlases). Records
for sensitive species may be coordinate-obscured at source; no precise
sensitive locations are added or shared here, and outputs are shown gridded.
